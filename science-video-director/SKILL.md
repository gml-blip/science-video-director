# 旁白驱动的科普短片

从用户已经确认的位置接手。沿用指定的画幅、配音服务、声音和参考片；新系列先明确受众、要回答的科学问题、片长和发布画幅。参考视频仅用来提取镜头节奏、景别变化、声音入点等手法。

1. **文案**。写逐字稿，每段标出一个观众应看懂的事实和对应画面。核实科学事实、单位和图像来源。读出术语和长句，留出观察复杂结构的时间。先让用户确认逐字稿。
2. **配音**。先用开场和最难念的一句试音，确认语言、声线、语速和停顿，再用相同设置按段生成 WAV。保存文本、音色、模型、种子等实际参数及完整旁白。用户已有 Qwen Studio 时用其服务和音色；也可用已有录音或 Windows 本地音色。工具见下文。听过或让用户确认实际声音后再锁定时间轴。
3. **计时与分镜**。从最终音频量取句首、关键词和停顿，记录秒数与帧率。用 [视听分镜工作表](references/shot-sheet.md) 设计每镜。相机在关键词之前起动，使观众听到名词时已经能认出对象。精确锁定点击、切开、揭示等事件。旁白重录后重新量取受影响的时间点。
4. **画面和声音设计**。给起止构图、空间参照、相机轨迹、缓动及材质，写出验收动作。同步标出音效触发帧、BGM 进退和旁白留白。优先试听授权清楚的现成音乐，登记署名；声音质感按本片偏好选择。给开场和最难镜头出代表关键帧，请用户确认。
5. **试片**。通常先交付开头 10 秒，放入实际旁白、候选配乐、音效和可播放的代码运镜。按固定帧率以帧号驱动相机，使用视差、遮挡或透视变化表现空间；在需要表达真实结构时使用适当的观测纹理或几何切面。用可复算的参数实现运动。先静音检查焦点与深度，再带声音核对关键词、动作和音乐。交付 MP4，请用户确认再继续。
6. **分段制作**。镜头独立保存，评审片带前后接点。将反馈拆成镜号、时间、要改变的属性和已认可的属性，只重做受影响的段。每次更新记录对应旁白版本。
7. **混音与验收**。保留旁白、音乐、音效分轨。对白下压低配乐，保留呼吸和停顿；按全片节奏调整音乐跨镜延续和片尾淡出。检查手机外放、最后一句、字幕遮挡、科学示意标注和素材署名。导出后完整播放，核对时长、帧率、声音和结尾。归档成片、分镜、确认稿、参数、分轨、渲染源码和授权。

## 安装包里的制作工具

以下路径相对本技能目录。将输出写入用户工程。安装器准备的 `bin/ffmpeg.exe` 可用于滤镜动画、图片序列编码、波形分析和最终混音。Windows PowerShell 自带的 System.Drawing 可逐帧计算几何、投影和遮挡，复杂场景可复用工程已有渲染器。

- 运行 `scripts/voice.ps1 -List` 枚举本机音色；传 `-TextFile 稿.txt -Voice 音色名 -Out 段.wav` 合成。对已有 Qwen Studio，加 `-Endpoint http://127.0.0.1:7860/v1/audio/speech` 并传该实例有效的 Voice ID。默认 Qwen 模型及 seed 可覆盖。已有旁白可直接进入计时步骤。
- 用 `scripts/mix.ps1 -Video 画面.mp4 -Narration 旁白.wav -Out 试片.mp4` 合成。可加 `-Effect 选中.wav -EffectAt 4 -Music 钢琴.mp3 -MusicAt 4.267 -MusicGain 0.14`。输入画面应为已编码的 H.264 MP4，旁白以当前段起点为零。混音工具适合首轮试听；多次音量变化按分镜用 FFmpeg 音量包络或剪辑工程处理。
